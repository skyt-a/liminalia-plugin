# liminalia-std-ui-modes（チャット風・HTML 表現パック）

チャット風会話表示、HTML 埋め込み、レイヤー文字、モーションテキストを有効化する公式プラグイン。

## 提供するコマンド

- `@chat-open`
- `@chat`
- `@chat-close`
- `@html`
- `@html-hide`
- `@layer-text`
- `@motion-text`

## 使い方

Studio の「プラグイン」画面で「チャット風・HTML 表現パック」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install std-ui-modes
```

インストール後、Studio を再起動すると有効になります。
