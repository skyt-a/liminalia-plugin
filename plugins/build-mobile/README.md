# liminalia-build-mobile（Android・iOS アプリ書き出し）

Android（APK・AAB）と iOS（実機・Archive・App Store Connect）の書き出しを有効化する公式プラグイン。

## 提供するコマンド

- `lim build android`
- `lim build ios`

## 使い方

Studio の「プラグイン」画面で「Android・iOS アプリ書き出し」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install build-mobile
```

インストール後、Studio を再起動すると有効になります。
