# liminalia-publish-stores（Steam・itch.io 配信とパッチ）

Steam・itch.io 公開、追加パック、差分パッチ、自動更新マニフェストと署名鍵生成を有効化する公式プラグイン。

## 提供するコマンド

- `lim publish`
- `lim pack`
- `lim patch`
- `lim update-manifest`
- `lim update-key`

## 使い方

Studio の「プラグイン」画面で「Steam・itch.io 配信とパッチ」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install publish-stores
```

インストール後、Studio を再起動すると有効になります。
