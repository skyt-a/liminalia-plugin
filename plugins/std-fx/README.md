# liminalia-std-fx（高度演出・漫画エフェクトパック）

ライティング、パーティクル、集中線・擬音、漫符、画面効果シェーダー、パラパラ漫画を有効化する公式プラグイン。

## 提供するコマンド

- `@lighting`
- `@light`
- `@shadow`
- `@reflection`
- `@lighting-off`
- `@particles`
- `@particles-off`
- `@speedlines`
- `@burst`
- `@emote`
- `@emote-off`
- `@effect`
- `@effect-off`
- `@flipbook`
- `@flipbook-off`

## 使い方

Studio の「プラグイン」画面で「高度演出・漫画エフェクトパック」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install std-fx
```

インストール後、Studio を再起動すると有効になります。
