# liminalia-ai

Liminalia Studio のシナリオ執筆のタブに「AI 相談」の欄を足すプラグイン。LIMINAL Forge の AI 相談を移したもの。

- 接続先: Codex（`codex app-server`）と Gemini（`agy`）。ローカルの CLI を使う（ログインは CLI の側で済ませておく）
- 決まった操作: 続きを提案・表現を磨く・この部分を膨らませる・情景を足す・演出を提案・やりたいことから命令・整合性チェック・シナリオを校正
- やりたいことから命令: 欄に「画面を揺らしてから暗転」のように書いて押すと、選んだ行の後ろに入れる命令の行を作る。エンジンの
  `ctx.commands()` から近い命令の仕様（引数・型・既定値・例）を渡し、案はエンジンの `ctx.check()` で検査して、誤りがあれば一度だけ直させる。
  命令だけの案は シナリオの校閲にかけない。エンジンにこの口が無いときは、仕様を渡さず検査もしない
- 台本の案は、かならず 本文の自己点検を通してから出す。反映は「置き換える」「後ろに足す」（⌘Z で戻せる）
- 対象は選んだ行（無ければカーソルの行）。まだ保存していない本文も渡す
- 正本の資料（既定は `data`）を文脈に入れる。欄の「設定」で変えられる（作品の `.liminalia/plugins/ai/settings.json` に覚える）

## 使い方

Studio の「プラグイン」→「公式のプラグイン」で「AI 相談」をインストールし、作品を開き直す。

右の欄の「AI 相談」を開く。操作は上の帯の「その他」のメニューにも並ぶ（結果は右の欄に出る）。

## 作り

- `src/studio-server.ts`（開発サーバー側。`./studio-server`）: `src/server/` の AiService が CLI を起こし、相談を流す
- `src/studio.ts`（制作画面側。`./studio`）: `src/client/` の欄と操作
- 受け渡しは `src/protocol.ts`。`@liminalia/sdk` は型だけを読む（エンジンの外に置いても動くように）
