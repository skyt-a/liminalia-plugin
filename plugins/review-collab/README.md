# liminalia-review-collab（レビューコメント・校正ツール）

Studio の「コメント」画面と、校正用テキスト抽出・台本書き出し（lim prose / lim script-export）を有効化する公式プラグイン。

## 提供するコマンド

- `lim prose`
- `lim script-export`

## 使い方

Studio の「プラグイン」画面で「レビューコメント・校正ツール」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install review-collab
```

インストール後、Studio を再起動すると有効になります。
