# liminalia-voice-production（ボイス収録・一括管理）

Studio の「ボイス」管理画面と、収録用 CSV 台本・ボイス番号固定（lim voice-script / lim voice-lock）を有効化する公式プラグイン。

## 提供するコマンド

- `lim voice-script`
- `lim voice-lock`

## 使い方

Studio の「プラグイン」画面で「ボイス収録・一括管理」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install voice-production
```

インストール後、Studio を再起動すると有効になります。
