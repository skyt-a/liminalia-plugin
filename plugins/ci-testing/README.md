# liminalia-ci-testing（CI 自動テスト・クラッシュ解析）

自動テスト（lim test）、到達探索（lim reach）、自動通しプレイ（lim playtest）、クラッシュ解析（lim crash）を有効化する公式プラグイン。

## 提供するコマンド

- `lim test`
- `lim reach`
- `lim playtest`
- `lim crash`

## 使い方

Studio の「プラグイン」画面で「CI 自動テスト・クラッシュ解析」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install ci-testing
```

インストール後、Studio を再起動すると有効になります。
