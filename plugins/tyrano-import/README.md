# liminalia-tyrano-import（TyranoScript 移行・書き戻し）

TyranoScript / TyranoBuilder（.ks）からの移行と書き戻し（lim import / lim backport / lim new --from-tyrano）を有効化する公式プラグイン。

## 提供するコマンド

- `lim import`
- `lim backport`
- `lim new --from-tyrano`

## 使い方

Studio の「プラグイン」画面で「TyranoScript 移行・書き戻し」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install tyrano-import
```

インストール後、Studio を再起動すると有効になります。
