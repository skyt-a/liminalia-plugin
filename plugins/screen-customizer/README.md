# liminalia-screen-customizer（画面パーツと CSS 編集）

Studio の「画面パーツと CSS」画面とテンプレート管理コマンド（lim screens）を有効化する公式プラグイン。

## 提供するコマンド

- `lim screens`
- `lim shot --screen`

## 使い方

Studio の「プラグイン」画面で「画面パーツと CSS 編集」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install screen-customizer
```

インストール後、Studio を再起動すると有効になります。
