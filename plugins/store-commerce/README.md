# liminalia-store-commerce（ストア課金・実績・プレゼンス）

ストア課金（@purchase）、進捗つき実績（@achieve）、プレイ状況表示（@presence）、更新チェック（@check-update）を有効化する公式プラグイン。

## 提供するコマンド

- `@purchase`
- `@restore-purchases`
- `@achieve`
- `@achieve-progress`
- `@presence`
- `@check-update`

## 使い方

Studio の「プラグイン」画面で「ストア課金・実績・プレゼンス」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install store-commerce
```

インストール後、Studio を再起動すると有効になります。
