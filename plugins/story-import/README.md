# liminalia-story-import（他ツールシナリオ取り込み）

Ink / Yarn Spinner / Ren'Py / Twine からのシナリオ変換取り込みを有効化する公式プラグイン。

## 提供するコマンド

- `lim import-ink`
- `lim import-yarn`
- `lim import-renpy`
- `lim import-twine`

## 使い方

Studio の「プラグイン」画面で「他ツールシナリオ取り込み」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install story-import
```

インストール後、Studio を再起動すると有効になります。
