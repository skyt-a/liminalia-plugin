# liminalia-std-adventure（探索・図鑑・HUD パック）

探索パート（@investigate）、マップ選択（@map-choice）、図鑑（@codex）、常設 HUD（@hud-button / @hud-text）を有効化する公式プラグイン。

## 提供するコマンド

- `@investigate`
- `@investigate-reset`
- `@map-choice`
- `@codex`
- `@codex-unlock`
- `@hud-button`
- `@hud-button-off`
- `@hud-text`
- `@hud-text-off`

## 使い方

Studio の「プラグイン」画面で「探索・図鑑・HUD パック」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install std-adventure
```

インストール後、Studio を再起動すると有効になります。
