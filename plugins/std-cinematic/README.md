# liminalia-std-cinematic（シネマティック演出パック）

スタッフロール、章タイトルカード、キーフレームアニメーション、レイヤーカメラ、立ち絵移動・揺れを有効化する公式プラグイン。

## 提供するコマンド

- `@staff-roll`
- `@chapter-card`
- `@chapter-end`
- `@keyframe`
- `@kanim`
- `@stop-kanim`
- `@layer-camera`
- `@reset-layer-camera`
- `@wait-camera`
- `@bg-place`
- `@chara-move`
- `@chara-shake`

## 使い方

Studio の「プラグイン」画面で「シネマティック演出パック」を検索してインストールするか、CLI で次を実行してください。

```sh
lim plugin install std-cinematic
```

インストール後、Studio を再起動すると有効になります。
